Use [Markdown](https://github.github.com/gfm/) to format your passages:

```md
Normal text with no formatting. You can do **bold** and *italics*, and [link to websites](https://codevirginia.org/learn)

# A Big Heading

## Smaller

### Smaller, etc.

- Bulleted list items
- Are good sometimes
```
:::

"Markdown" is a sort of programming language that lets you do basic formatting using plain-text characters. The Chapbook story format that we use in this trail guide lets you write Markdown in your passages, opening up some formatting options that you might find useful.

There are a large list of different Markdown formatting options to try; check out [the full spec with examples here](https://github.github.com/gfm/).
