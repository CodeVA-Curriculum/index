## About CSS (Cascading Style Sheets)

"CSS" is a kind of programming language designed for styling HTML documents like our Twine passages. CSS allows yAdaptationou to do more customized and powerful formatting and styling than Chapbook's built-in Markdown formatting.

CSS is a whole language unto itself, and there are very few limits on what you can accomplish with it if you are committed. That said, you'll probably benefit more from learning the basics of Twine before spending a lot of time and energy learning CSS. If you are interested in learning CSS by looking at examples, [w3schools](TODO) has great resources. If you're more interested in articles about doing different things with CSS, the [CSSTricks](TODO) website is a good place for that (though you may not understand everything on there until you've had some more experience/practice).
